// 05 — ВОПРОСЫ

Частые вопросы

Коротко о том, что обычно спрашивают перед установкой.

На каких системах работает приложение?

Windows 10/11 (64-bit) и Linux (deb/rpm). Приложение написано на Java (JavaFX), поэтому при установке ставится встроенная среда выполнения — отдельно Java устанавливать не нужно.

Нужен ли интернет для работы?

Нет. Все расчёты, нормативная база и справочники хранятся локально в SQLite на вашем компьютере. Интернет нужен только для проверки обновлений и загрузки новых модулей.

Где хранятся мои расчёты и проекты?

В локальной базе данных на вашем диске. Никакие данные не отправляются на сервер. Вы можете делать резервные копии базы и переносить её между компьютерами.

Приложение бесплатное?

Базовая версия с калькуляторами, справочниками и поиском по нормативам — бесплатна. Отдельные расширенные модули (например, генератор отчётов с шаблонами) могут распространяться по подписке.

Насколько актуальна нормативная база?

База обновляется по мере выхода изменений в СП и ГОСТ. В приложении отображается дата актуализации каждого документа и есть отметка «проверено». Перед сдачей проекта всегда сверяйтесь с официальным источником.

Можно ли добавить свой модуль или калькулятор?

Да, архитектура приложения модульная. Если вы разработчик — можете написать свой HTML-модуль и подключить его. Если нет — напишите нам через форму обратной связи, мы рассмотрим добавление функции.

Как перенести лицензию на другой компьютер?

Привязка идёт к учётной записи, а не к «железу». Достаточно войти под своей учётной записью на новом компьютере — настройки и база подтянутся (если включена синхронизация) или переносятся вручную файлом базы.
