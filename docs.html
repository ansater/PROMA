Документация ProjectHelper

Руководство пользователя: как установить приложение, разобраться в интерфейсе и работать с модулями.

01Обзор

ProjectHelper — настольное приложение для проектировщиков, объединяющее расчётные инструменты, нормативную базу и справочники в одном окне. Работает офлайн, данные хранятся локально.

Ключевые принципы:

  • Модульность — каждая функция это отдельный модуль, подключаемый к оболочке.
  • Локальность — никаких обязательных облачных сервисов.
  • Скорость — поиск по нормативной базе и расчёты выполняются мгновенно.
Системные требования: Windows 10/11 (64-bit) или Linux (deb/rpm), 4 ГБ ОЗУ, 500 МБ на диске. Java устанавливать отдельно не нужно — она встроена.

02Установка

Windows

  1. Скачайте установщик ProjectHelper-setup.exe со страницы загрузки.
  2. Запустите его и следуйте шагам мастера.
  3. После установки запустите приложение из меню «Пуск».

Linux

sudo dpkg -i projecthelper_1.0_amd64.deb
sudo apt --fix-broken install   # при необходимости зависимостей
Первый запуск: приложение создаст локальную базу данных в папке пользователя и предложит выбрать тему оформления.

03Интерфейс

Окно приложения разделено на две зоны:

  • Слева — сайдбар с навигацией по модулям (Расчёты, Нормативы, Справочники, Документы, Проекты, Настройки).
  • Справа — рабочая область, куда загружается выбранный модуль.

Сверху расположена панель с названием текущего модуля и кнопкой возврата на главную (дашборд с плитками).

04Калькуляторы

Модуль содержит набор расчётных инструментов. Каждый калькулятор — форма ввода слева и результат с предпросмотром справа.

Как выполнить расчёт

  1. Выберите калькулятор из списка.
  2. Заполните поля (единицы измерения подставляются по умолчанию).
  3. Нажмите «Рассчитать» — результат появится в правой части.
  4. Нажмите «Сохранить в проект», чтобы привязать расчёт к текущему проекту.

Доступные калькуляторы

Совет: история расчётов хранится автоматически — её можно открыть из модуля «Проекты».

05Нормативная база

Поиск по СП, ГОСТ и СНиП. Поддерживается два режима:

  • Быстрый поиск — по номеру документа или ключевым словам.
  • Семантический поиск — по смыслу запроса (например, «как посчитать прогиб» найдёт нужный пункт).

Работа с документами

  1. Введите запрос в строку поиска.
  2. Выберите документ из результатов — откроется текст с подсветкой совпадений.
  3. Нажмите «В избранное», чтобы закрепить документ на главной.
Важно: в карточке каждого документа указана дата актуализации. Перед сдачей проекта сверяйтесь с официальным источником.

06Справочники

Таблицы значений и сортаменты: металлопрокат, трубы, единицы измерения, плотности материалов.

Данные можно фильтровать и копировать в буфер обмена или экспортировать в CSV.

07Отчёты

Результаты расчётов можно оформить в виде документа:

  • PDF — для печати и приложения к пояснительной записке.
  • Word (.docx) — для дальнейшего редактирования.

Отчёт включает исходные данные, формулы, результат и ссылки на использованные нормативы.

Совет: шаблон отчёта можно настроить в разделе «Настройки → Отчёты» (логотип организации, шрифт, поля).

08Проекты

Каждый проект — это папка с сохранёнными расчётами, заметками и прикреплёнными документами.

  1. Создайте проект на дашборде («Новый проект»).
  2. Привязывайте расчёты к проекту кнопкой «Сохранить в проект».
  3. Экспортируйте проект целиком в архив для передачи коллеге.
